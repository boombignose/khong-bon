# ตรวจคลิปก่อนประกอบ

สถานะเริ่มต้น: NEEDS_HUMAN_REVIEW

- [ ] รูปร่าง สี ใบหน้า และฉากตรงภาพอ้างอิงทั้ง 3 ช็อต
- [ ] มีสิ่งของผู้พูดตัวเดียว ไม่มีแขนขางอกหรือคนเพิ่ม
- [ ] ฟังภาษาไทยครบ ตรงบท ไม่มีคำพูดเพิ่ม
- [ ] เสียงบุคลิกเดียวกันทั้ง 3 ช็อต
- [ ] ซับตรงเสียงและไม่บังหน้า/ปุ่มบนแพลตฟอร์ม
- [ ] ดูคลิปประกอบจบครบ 24 วินาที
