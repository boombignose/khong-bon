## Facebook

ผมสร้างชุดทำคลิป “ของใช้พูดได้” ด้วย ChatGPT / Claude + Google Flow 🎬
แก้วกาแฟบ่นเจ้าของ แอร์บ่นคนห่มผ้า ตะกร้าผ้าบ่นคนไม่ยอมซัก 😂
พร้อม Skill ภาษาไทย บท Prompt ภาพตั้งต้น และตัวอย่างคลิป
พิมพ์ “ของบ่น” เดี๋ยวส่งให้ครับ!

## Kruoop

ชื่อโพสต์: แจกฟรี: ของบ่น — ชุดสร้างคลิปของใช้พูดได้ด้วย AI

ถ้าแก้วกาแฟพูดได้ มันอาจบอกว่า “เรียกผมว่าแก้วโปรด แต่ไม่เคยล้างผมเลย” ☕😂

ผมทำชุด “ของบ่น” ให้ลองเปลี่ยนของใช้ใกล้ตัวเป็นตัวละครเล่าความในใจ ด้วย ChatGPT / Claude + Google Flow

ในชุดมี Skill ภาษาไทย, ภาพตัวละครตั้งต้น 4 ตัว, ตัวอย่างบท 3 ช็อต, Prompt สำหรับ Flow, สตอรีบอร์ด, ซับ และตัวประกอบคลิปในเครื่อง

กรอกแค่สิ่งของ + นิสัย + เรื่องที่จะบ่น เช่น แอร์ที่เจ้าของเปิดจนหนาวแล้วห่มผ้า หรือตะกร้าผ้าที่ได้ยินคำว่าพรุ่งนี้ทุกวัน

โค้ดและเอกสารแจกฟรี MIT แก้และประยุกต์ต่อได้ ส่วนการสร้างภาพ/คลิปใช้บัญชีและเครดิตของบริการที่เลือก ตัวอย่างคลิปเป็นผลทดลอง ต้องดูและฟังตรวจอีกครั้งก่อนโพสต์
