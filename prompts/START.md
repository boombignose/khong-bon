# คัดลอกไปใช้ใน ChatGPT / Claude

แนบ SKILL.md และ STORY.md หรือวางเนื้อหาในแชต แล้วสั่ง:

```text
สร้างตอน “ของบ่น” คลิปสิ่งของพูดได้ ภาษาไทย 24 วินาที
สิ่งของ: แก้วกาแฟ
นิสัย: เหนื่อยใจแต่กวนแบบสุภาพ
เรื่องบ่น: เจ้าของเรียกว่าแก้วโปรด แต่ไม่ยอมล้าง

เปิดประเด็น → ขยายมุก → จบขำ เป็น 3 ช็อต ช็อตละ 8 วินาที
ผู้พูดสิ่งของตัวเดียว ไม่มีคน ไม่มีแขนขาเพิ่ม
รักษารูปร่าง สี ฉาก และบุคลิกเสียงทั้งตอน
บทไทยสั้น อ่านทัน แบ่งบรรทัดซับได้
ส่ง story.json ตาม STORY.md พร้อมคำอธิบายตัวละครและเหตุผลของมุก
ถ้ารันสคริปต์ได้ ให้ตรวจ check แล้วสร้าง pack ในโฟลเดอร์ใหม่
```

เปลี่ยนเพียงสิ่งของ นิสัย และเรื่องบ่นสำหรับตอนใหม่ หากทำสินค้า ให้แนบข้อเท็จจริงของสินค้าและห้ามเพิ่มคำกล่าวอ้างที่ไม่ได้ให้
