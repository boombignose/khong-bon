# ทำคลิปใน Google Flow

ตรวจ UI จริงก่อนทำ เพราะรุ่นโมเดลและเครดิตอาจเปลี่ยนได้ [เริ่มใช้ Flow](https://support.google.com/flow/answer/16353333) · [สร้างคลิป/ใส่ภาพตั้งต้น](https://support.google.com/flow/answer/16353334)

1. เปิด project ใหม่ เลือก Video, แนวตั้ง 9:16, ความยาว 8s และผลลัพธ์ครั้งละ 1 คลิป
2. เลือกโมเดลที่รองรับเสียงพูด ดูค่าเครดิตก่อน Generate หากไม่มี 8s หรือไม่มีเสียง ให้เลือกโมเดลที่รองรับ
3. ใส่ภาพ reference เป็น start frame ในโหมด Frames ตาม UI ที่มี ตรวจรูปร่างและฉากในภาพก่อนเลือก ผู้ใช้อัปโหลดเฉพาะภาพที่มีสิทธิ์ใช้ และยืนยันข้อความเรื่องสิทธิ์ด้วยตนเองเมื่อ Flow ขอ
4. วาง shot-01.txt แล้วสร้าง 1 เทค ดูครบและฟังเสียงจริง ถ้าตรงแล้วค่อยทำ 02 และ 03 ใช้ภาพเริ่มต้นเดิมเมื่อเหมาะสม หรือเฟรมจากเทคก่อนที่ตรวจแล้ว
5. ดาวน์โหลดแต่ละช็อต เก็บชื่อเป็น shot-01.mp4, shot-02.mp4, shot-03.mp4 อย่าเลือกเทคจากภาพปกอย่างเดียว

## ซ่อมเฉพาะจุด

ใช้ Prompt เดิมและ reference เดิม เพิ่มคำสั่งที่สัมพันธ์กับข้อผิดพลาดเพียงจุดเดียว ไม่ต้องสุ่มหลายเทคก่อนรู้ว่าเสียตรงไหน

| ปัญหา | สิ่งที่ปรับ |
| --- | --- |
| พูดไม่ทัน | ตัดคำที่ไม่จำเป็นใน line ก่อนเจนใหม่ ไม่เร่งเสียง |
| มีคนหรือแขนขาเพิ่ม | ย้ำ sole object speaker, no humans, no arms or legs และลด action |
| เสียงเปลี่ยน | คงคำอธิบาย voice เดิม ทดลองโมเดลเดียวกัน หรือใช้เสียงพากย์เดียวใน editor |
| รูปร่าง/ฉากเปลี่ยน | ใช้ start frame ที่ตรวจแล้ว ลดกล้องเคลื่อนและรายละเอียดที่ขัดกัน |
| ข้อความงอกบนภาพ | ใช้ภาพไม่มีตัวอักษรและ no written captions เผาซับภายหลัง |

## เกณฑ์ตรวจ

ตรวจรูปร่าง/สี/ตำแหน่งหน้าและฉาก, มีผู้พูดคนเดียว, บทไทยครบและถูกต้อง, บุคลิกเสียงคงที่, ปากสัมพันธ์กับคำพูด, ไม่มีสิ่งผิดรูป, ซับตรงจังหวะและไม่ทับปุ่มของแพลตฟอร์ม ดู final.mp4 จบอีกครั้งหลังประกอบ

ตัว pack/assemble ตรวจโครงสร้างและไฟล์ได้ ไม่ตัดสินความขำ สำเนียง ความตรงของปากหรือความต่อเนื่องของโมเดล ถ้ายังไม่ได้ตรวจด้วยคนให้คงสถานะ NEEDS_HUMAN_REVIEW
