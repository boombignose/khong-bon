# ของบ่น · Khong Bon

เปลี่ยนสิ่งของ + นิสัย + เรื่องที่จะบ่น เป็นคลิปแนวตั้ง 24 วินาที: เปิดประเด็น → ขยายความขำ → จบมุก ใช้ตัวละครสิ่งของผู้พูดเพียงตัวเดียว บ่นพฤติกรรมของเจ้าของอย่างขำ ๆ

## สร้างตอน

ใช้รายละเอียดที่ผู้ใช้ให้ ถ้ามีแค่สิ่งของให้เลือกนิสัยและเรื่องบ่นที่สัมพันธ์กับหน้าที่ของมัน ไม่ต้องถามเพิ่มเมื่อทำต่อได้ หากเป็นตอนต่อของตัวเดิม ให้อ่าน character และภาพที่อนุมัติแล้วก่อนเขียน

อ่าน [รูปแบบ story.json](references/STORY.md) และ [ตัวละครตั้งต้น](references/CHARACTERS.md) เฉพาะตัวที่ใช้ สร้างไฟล์ story.json ตามรูปแบบนั้น มี 3 scenes ช็อตละ 8 วินาที คำอธิบายภาพ/กล้อง/เสียงเป็นอังกฤษ บทพูดเป็นไทยสั้น ๆ ไม่เกิน 85 ตัวอักษรต่อช็อต และแบ่งบรรทัดซับให้คนอ่านง่าย ตัวอักษรเป็นเพียงเพดานไฟล์ ไม่รับประกันว่าพูดทัน ให้ลองอ่านบทออกเสียง

รักษารูปร่าง สี ดวงตา ตำแหน่งปาก ฉาก และบุคลิกเสียงเดียวกันทั้งตอน ให้แสดงอารมณ์ผ่านตา/คิ้ว/ปาก แทนการเพิ่มแขนขา ใช้ต้นแบบ original stylized 3D ไม่อ้างชื่อสตูดิโอหรือแฟรนไชส์

ถ้าใช้กับสินค้า ใช้ข้อมูลจริงที่ผู้ใช้ให้ ไม่เพิ่มสรรพคุณ ประสิทธิภาพ ราคา หรือประสบการณ์ลูกค้าที่ไม่มีหลักฐาน ตัวอย่างน้ำยาล้างจานเป็นสินค้าสมมติ ไม่มีแบรนด์ และไม่อ้างสรรพคุณ

## ส่งออกชุดผลิต

เมื่อมีเครื่องมือไฟล์ ให้รันจาก path ของ Skill จริง:

```sh
python3 <skill-directory>/scripts/khong_bon.py check story.json
python3 <skill-directory>/scripts/khong_bon.py pack story.json --out episode-01
```

เลือกโฟลเดอร์ปลายทางใหม่ สคริปต์ไม่ทับชุดเดิม ส่งลิงก์ให้ผู้ใช้เปิด storyboard.html พร้อม character.txt, image-prompt.txt, shot-01.txt ถึง shot-03.txt, subtitles.srt/ass และ QC.md ถ้าเป็นแชตที่รัน Python ไม่ได้ ให้ส่ง JSON และข้อความ Prompt ให้บันทึกลงเครื่อง อย่าอ้างว่ารันคำสั่งแล้ว

ไฟล์ภาพตั้งต้นอยู่ใน assets/ ของ Skill: mug-reference.png, aircon-reference.png, laundry-reference.png และ dish-soap-reference.png เลือกให้ตรงตัวละครเท่านั้น ถ้าเปลี่ยนรูปร่าง/สี ให้สร้างภาพใหม่ตาม image-prompt.txt ไม่ส่งภาพเดิมเป็นตัวละครใหม่

## สร้างและประกอบคลิป

อ่าน [วิธีทำใน Flow และ QC](references/FLOW.md) การสร้างชุดไฟล์ไม่ใช่การเรนเดอร์วิดีโอ และไม่ใช่การอนุญาตให้ใช้บัญชี จ่ายเครดิต หรือเผยแพร่เพิ่มโดยอัตโนมัติ ใช้ขอบเขตที่ผู้ใช้อนุญาตไว้แล้ว หากไม่มี ให้ส่ง Prompt ให้ผู้ใช้ทำใน Flow ตรวจรุ่นโมเดล ระยะเวลา อัตราส่วน และเครดิตที่ UI จริงก่อนสร้าง

เมื่อได้คลิปจริง 3 ช็อต ให้ฟังภาษาไทยและดูภาพครบทุกช็อต ปรับ line/บรรทัดใน story.json และเวลาซับเมื่อเสียงคลาดเคลื่อน ซับเริ่มที่ 0.6 วินาทีและจบที่ 7.4 วินาทีของแต่ละช็อตเป็นค่าตั้งต้น ไม่ใช่ผลถอดเสียง

```sh
python3 <skill-directory>/scripts/khong_bon.py assemble story.json --clips shot-01.mp4 shot-02.mp4 shot-03.mp4 --out final.mp4
```

ต้องมี FFmpeg/ffprobe และตัวกรอง libass สคริปต์ตรวจ 3 คลิปที่มีภาพและเสียง ความยาวใกล้ 8 วินาที ปรับเป็น 720×1280 โดยใส่ขอบเมื่ออัตราส่วนต่างกัน เผาซับไทยด้วยฟอนต์ที่ให้มา และไม่แก้คลิปต้นฉบับ ไม่ทำการ sync เสียงหรือรับรองความต่อเนื่องของโมเดล

รายงานสิ่งที่สร้างจริง แยกสตอรีบอร์ด ภาพอ้างอิง คลิปเรนเดอร์ และคลิปผ่าน QC อย่าเรียกคลิปว่าผ่าน QC ถ้ายังไม่ได้ดูและฟังครบ
